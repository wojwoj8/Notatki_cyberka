## Elastic Stack

Jest to zbiór narzędzi do analizy i wizualizacji danych w różnych formatach i z różnych źródeł.

Elasticsearch to silnik wyszukiwania pełnotekstowego i analizy służący do przechowywania dokumentów w formacie JSON. Elasticsearch jest ważnym komponentem służącym do przechowywania, analizowania, korelacji danych itp. Elasticsearch obsługuje RESTFul API do interakcji z danymi.

### Logstach

Jest do data processing engine do danych z różnych źródeł i nakłada na nie filtry lub je normalizuje. Dalej wysyła na nasłuchujący port albo do Kibany. Składa się z inputu, filtra i outputu.

### Beats

Beats is a host-based agent known as Data-shippers that is used to ship/transfer data from the endpoints to elasticsearch. Each beat is a single-purpose agent that sends specific data to the elasticsearch.

### Kibana

To web-based data visualization that works with elasticsearch to analyze, investigate and visualize the data stream in real-time. It allows the users to create multiple visualizations and dashboards for better visibility
